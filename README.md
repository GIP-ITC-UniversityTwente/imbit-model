# IMBIT ABM 

## Running the model

1. Clone this repo to your device.
2. Download the dataset from Zenodo.
3. Open NetLogo and run the model

## Additional information
- Separate repository for preprocessing the IMBIT data: [link](https://github.com/GIP-ITC-UniversityTwente/imbit_preprocessing)

- Current documentation of the model (unfinished): [link](https://www.overleaf.com/7755863841pgspzydndqpg#972b47)

- For documentation of the foi that RIVM provided refer to files under `documentation/foi` subfolder.
